Deskary

Sistema de gestio de bibliotecas

Sistema web para la gestión de bibliotecas con landing pública y panel administrativo para gestionar libros, clientes y préstamos. Desarrollado con Angular, NestJS, PostgreSQL y Docker mediante una arquitectura basada en APIs REST.
